# Projects

## Knubby: Knitting Project Management App

- Developed a mobile application for knitters.
- Integrated the [Ravelry API](https://www.ravelry.com/api#patterns_patterns) to retrieve a random knitting pattern every time the app is opened.
- Add your projects, take pictures, and track rows and progress.
- Included a basic glossary for common knitting shorthand.
- Profile page with saved patterns.
- YouTube demo: [Watch the demo](https://youtu.be/aXp07r8gh3U)

## PizzaProf: Small Business Management App
